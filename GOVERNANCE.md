# Governance

**Classification:** RESEARCH
**Claim level:** 0 (design target / intent constant)
**Experimental validation:** false
**Governing source:** [ADL-Governance](https://github.com/beyond-repair/ADL-Governance)

This repository freezes a historical engineering target used in Coherence Drive scaling discussions. It is not a device, solver, or measurement campaign.

## Allowed claims

- State F/P = 3e-8 N/W = 30 uN/kW as a shared yardstick.
- Point upstream to theory and phenomenology repos.

## Forbidden claims

- Measured thrust or built hardware.
- Fitting coupling constants solely so a model hits this number and calling that a prediction.
- Claim level >= 4 without a documented measurement protocol and data (ADL CLAIM_VALIDATION.md rule 4).

## Software vs physics

A green CI run here only checks unit identity of the published constant. It does not raise physics claim level.
